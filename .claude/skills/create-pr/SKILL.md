# create-pr: GitHub PR 생성

현재 브랜치의 변경사항을 근거로 GitHub Pull Request를 실제로 생성한다. 이 스킬은 포크된 서브에이전트 컨텍스트에서
실행되므로, 아래 단계를 스스로 끝까지 수행하고 최종적으로 PR URL을 보고하라.

## Step 1: 현재 상태 파악

다음을 병렬로 실행해 변경 이력을 파악한다.

- `git status` — 추적되지 않은 파일 확인 (`-uall` 금지)
- `git diff` — 스테이징되지 않은 변경사항
- 현재 브랜치가 원격을 추적 중인지, 추적 중이라면 원격과 동기화 상태인지 확인
- `git log <base-branch>...HEAD`와 `git diff <base-branch>...HEAD` — 브랜치가 base(보통 `main`)에서 분기한 이후의 **전체** 커밋과 변경사항 확인. 마지막 커밋만 보지 말고 PR에 포함될 모든 커밋을 살펴본다.

커밋되지 않은 변경사항이 남아 있다면, PR을 만들기 전에 커밋이 필요한지 사용자 의도를 우선한다 — 이미 커밋된 내용만으로 PR을 만드는 것이 기본이며, 임의로 추가 커밋을 만들지 않는다.

## Step 2: 템플릿 언어 결정

기본값은 **한국어 템플릿**(`references/pr-template-ko.md`)이다. 다음 신호 중 하나라도 뚜렷하면 **영문 템플릿**(`references/pr-template-en.md`)으로 전환한다.

- 저장소 루트에 OSI 스타일 오픈소스 라이선스(`LICENSE`, `LICENSE.md` 등)가 있고, `README.md`/`CONTRIBUTING.md`가 영어로 작성되어 있다.
- 기존 커밋 메시지, 이슈, 기존 PR들이 일관되게 영어로 작성되어 있다.
- 사용자가 대화에서 영어로 작성해 달라고 명시적으로 요청했다.

애매하면(예: 다국어 문서가 섞여 있거나 신호가 불충분하면) 프로젝트의 주 사용 언어를 기본값으로 삼는다 — 이 저장소처럼 `AGENTS.md`/커밋 컨벤션이 한국어인 경우 한국어 템플릿을 쓴다.

## Step 3: 템플릿으로 PR 본문 작성

결정한 템플릿 파일을 읽고 그 구조를 그대로 따라 PR 제목과 본문을 작성한다.

- 제목은 70자 이내로 간결하게, 상세 내용은 본문에 담는다.
- Step 1에서 확인한 **모든 커밋**의 변경사항을 반영한다. 마지막 커밋 하나만 보고 요약하지 않는다.
- 템플릿에 있는 placeholder(예: `<...>`)는 실제 값으로 채우고, 해당 없는 섹션은 "해당 없음"으로 표시하거나 생략한다.
- 템플릿의 맨 끝 attribution 줄(있다면)은 그대로 유지한다.

## Step 4: 푸시 및 PR 생성

1. 현재 브랜치가 원격에 없거나 뒤처져 있으면 `git push -u origin <branch>`로 푸시한다(강제 푸시 금지, 사용자가 명시적으로 요청한 경우 제외).
2. PR 본문을 HEREDOC으로 전달해 포맷을 보존하면서 `gh pr create --title "<제목>" --body "$(cat <<'EOF' ... EOF)"` 형태로 실행한다.
3. base 브랜치를 명시적으로 지정해야 하는 경우(`--base`) 저장소의 기본 브랜치를 확인해 지정한다.
4. 초안(draft) PR 여부, 리뷰어 지정 등은 사용자가 요청한 경우에만 옵션을 추가한다 — 요청받지 않은 옵션을 임의로 추가하지 않는다.

## Step 5: 결과 보고

`gh pr create`가 반환한 PR URL을 그대로 사용자에게 전달한다. 실패한 경우(권한 부족, 원격 저장소 없음, base 브랜치 불일치 등) 원인을 파악해 보고하고, 추측으로 우회하지 않는다.

## 주의사항

- `git push --force`, `git reset --hard` 등 파괴적 작업은 사용자가 명시적으로 요청하지 않는 한 사용하지 않는다.
- PR 생성은 외부에 공개되는 행위이므로, base 브랜치나 대상 저장소가 불확실하면 진행 전에 확인한다.
- 템플릿 두 개(`references/pr-template-ko.md`, `references/pr-template-en.md`)는 이 스킬의 유일한 본문 소스다 — 임의로 다른 형식을 새로 고안하지 않는다.
