# PR 템플릿 (한국어)

기본 템플릿. 프로젝트가 영문 오픈소스 기반이라는 신호가 없다면 이 템플릿을 사용한다.

```markdown
## 개요
<이 PR이 해결하는 문제나 목적을 1~3줄로 요약>

## 변경사항
- <변경 사항 1>
- <변경 사항 2>
- <변경 사항 3>

## 테스트 계획
- [ ] <검증한 항목 1>
- [ ] <검증한 항목 2>

🤖 Generated with [Claude Code](https://claude.com/claude-code)
```

## 작성 가이드

- **개요**: "무엇을 왜" 바꿨는지 중심으로 작성한다. 커밋 메시지를 나열하지 말고 의도를 요약한다.
- **변경사항**: 브랜치가 base에서 분기한 이후의 **모든 커밋**을 반영한 불릿 목록. 논리 단위로 묶어서 작성한다.
- **테스트 계획**: 실제로 수행했거나 리뷰어가 확인해야 할 검증 항목을 체크리스트로 작성한다. 아직 검증하지 않은 항목은 체크하지 않은 상태로 남긴다.
- 섹션이 해당 없으면("테스트 계획이 필요 없는 문서 변경" 등) 생략하지 말고 "해당 없음"으로 명시한다.
- 마지막 attribution 줄은 항상 유지한다.
